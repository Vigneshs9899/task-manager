# Task Manager

A simple and responsive Task Manager web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Delete tasks
- View task list instantly
- Stores tasks using Local Storage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## Project Overview

The Task Manager allows users to create and manage daily tasks directly in the browser. Tasks are stored using the browser's Local Storage, ensuring data remains available even after refreshing the page.

## How It Works

1. Enter a task in the input field.
2. Click the "Add" button.
3. The task is displayed in the task list.
4. Tasks are saved in Local Storage.
5. Delete tasks when they are no longer needed.
